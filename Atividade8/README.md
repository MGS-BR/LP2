# Atividade 8 — PMatrizes

Aplicação WinForms com exercícios sobre **vetores, matrizes e ArrayList**, usando caixas de entrada (`InputBox`) para coleta de dados:

- Preenchimento e inversão de um vetor de 20 posições;
- Remoção de item de uma lista de nomes;
- Cálculo de médias de notas de 20 alunos;
- Contagem de caracteres de nomes digitados;
- Correção de gabarito de prova comparando respostas de vários alunos.
